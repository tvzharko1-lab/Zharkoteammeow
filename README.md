 Posture Guard AI
Веб-приложение для контроля осанки, дистанции до экрана и частоты моргания в реальном времени с помощью веб-камеры. Работает прямо в браузере за счёт локальной нейросети Google MediaPipe, без отправки видео на сторонние серверы.
🔗 Ссылки на проект:
* GitHub-репозиторий: [https://github.com/tvzharko1-lab/Zharkoteammeow.git](https://github.com/tvzharko1-lab/Zharkoteammeow.git)
* Рабочая версия (деплой): [https://tvzharko1-lab.github.io/Zharkoteammeow/](https://tvzharko1-lab.github.io/Zharkoteammeow/)
Возможности
* Контроль осанки: следит за положением головы и предупреждает, если вы сутулитесь.
* Детекция зевков: определяет усталость по открытию рта.
* Контроль дистанции: отслеживает, не слишком ли близко (или далеко) вы сидите от монитора.
* Подсчет морганий: считает количество морганий за последнюю минуту.
* Звуковые уведомления: подает сигнал при фиксации нарушений.
* Режим «Картинка в картинке» (PiP): позволяет вывести компактный индикатор статуса поверх остальных окон.
 Технологии
* HTML5 / CSS3
* JavaScript (ES Modules)
* Google MediaPipe (`Tasks Vision` / `Face Landmarker`)
* Web Audio API
 Как использовать
1. Перейдите на [сайт приложения](https://tvzharko1-lab.github.io/Zharkoteammeow/).
2. Разрешите доступ к веб-камере в браузере.
3. Сядьте ровно и нажмите кнопку «Калибровка» для настройки базовых параметров под ваше положение.
